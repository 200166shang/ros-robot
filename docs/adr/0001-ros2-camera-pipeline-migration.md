# Port the camera pipeline to ROS 2 without changing processing behavior

Migrate camera capture, image decoding, and image encoding as separate ROS 2 C++ nodes while preserving the existing topics, frame-divider semantics, and OpenCV/MPP/RGA processing paths. Select the software or Rockchip backend at build time with a CMake option whose default follows the target platform, so both paths can be built and measured on the Orange Pi. Keep shared-memory transport, `CameraInfo`, and the tracking-annotated `/camera/image_det_track` stream outside this camera migration; the encoder's default route is `/camera/image_raw` to `/camera/image_raw/compressed`. Validate on ROS 2 Foxy using live image preview and reported ROS 2 performance measurements; no ROS 1 runtime is available for a version-to-version benchmark.
